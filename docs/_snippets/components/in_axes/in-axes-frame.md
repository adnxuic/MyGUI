| Inspector field | Control | Meaning | Values / default | Persisted / runtime key |
| --- | --- | --- | --- | --- |
| Facecolor | Color choice | Background fill color of the inset Axes box. | Hex color; default `#ffffff` | `properties.facecolor` |
| Frameon | Checkbox | Draws the background rectangle and bounding box spines of the inset. | `true` or `false`; default `true` | `properties.frameon` |
| Edgecolor | Color choice | Border / frame stroke color of the inset bounding box. | Hex color; default `#000000` | `properties.edgecolor` |
| Linewidth | Number | Border / frame stroke width in points. | Finite number `>= 0`; default `0.8` | `properties.linewidth` |
