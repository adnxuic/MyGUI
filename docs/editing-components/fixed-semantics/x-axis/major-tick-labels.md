# Major Tick Labels Component

The **Major Tick Labels** component controls the font styling, orientation, alignment, padding, and background frame formatting of tick label text strings generated at major tick locations.

These properties remain editable from this child Inspector and from the
owning X/Y Axis **Ticks & Labels** dialog. Label text is generated by the
Axis-owned Formatter; a Fixed Formatter must be paired with an equal-length
Fixed Locator, edited row-by-row in the unified dialog.
